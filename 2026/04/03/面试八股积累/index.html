装饰器是什么？

装饰器是 Python 中的一种高级特性，用于在不修改原函数代码的情况下动态地增强函数的功能。它本质上是一个接受函数作为参数并返回新函数的高阶函数。装饰器的使用可以让代码更加简洁、模块化和 Pythonic。

装饰器在实际开发中有广泛的应用，例如：

  1. 日志记录：记录函数调用信息。

  2. 权限验证：检查用户是否有权限执行某些操作。

  3. 性能监控：计算函数执行时间。

  4. 缓存：存储函数的计算结果以提高性能。

深拷贝和浅拷贝是什么？

在 Python 中，深拷贝（deepcopy）会递归复制对象及其所有子对象，生成一个与原对象完全独立的副本，修改副本不会影响原对象。

核心特性

  • 递归复制：不仅复制顶层结构，还会复制所有嵌套的可变对象（如列表、字典）。

  • 数据隔离：新旧对象之间无共享引用，适合需要完全独立数据的场景。

  • 内存开销：由于复制了整个对象树，深拷贝在大型复杂结构中会消耗更多内存和 CPU。

与浅拷贝的区别

  • 浅拷贝（copy.copy()）：只复制顶层结构，嵌套可变对象仍共享引用，修改嵌套部分会影响原对象。

  • 深拷贝（copy.deepcopy()）：递归复制所有层级，任何修改都不会影响原对象。

适用场景

  • 配置或数据备份：避免修改副本时污染原始数据。

  • 嵌套结构处理：如 JSON、图形对象、复杂数据模型。

  • 测试与调试：确保测试数据与生产数据隔离。

为什么要用递归？它与for循环有什么区别？

使用递归是为了让代码更简洁，结构更清晰，尤其适合处理具有“自相似”特征的问题，与for循环相比，递归的写法更短，更符合“每一层逻辑都做同样的事”的逻辑，可读性强，代码更贴近问题本身的结构。
但是递归如果没有出口条件，容易栈溢出，在对性能敏感的程序中，可能需要用循环或栈代替递归。

GIL全局解释锁

GIL是CPython解释器中的一种互斥锁机制，用于证明同一时刻只有一个线程执行Python字节码。它的设计初衷是简化内存管理，尤其是引用计数的线程安全问题。但是在多核CPU上限制了多线程的并行执行。

工作原理：每个线程在执行python字节码之前先获取GIL，当一个线程获取GIL之后，其他线程必须等待该线程释放GIL才能继续执行。

如何避免GIL：
将python代码转为C语言代码；
使用multiprocessing多进程模块；
使用C扩展模块，在C扩展模块中释放GIL，允许其他线程执行python代码；
使用numpy矢量化计算。
