AI应用开发工程师面试题（基于技术栈）

一、Python & 工程能力

Q1：Python 中常用的数据结构有哪些？各自适用场景？

参考回答：

Python 常用数据结构包括：

  • list：有序、可变，适用于顺序数据存储
  • dict：键值对结构，查找复杂度 O(1)，适合索引和映射
  • set：去重与集合运算
  • tuple：不可变，适合只读数据

在 Agent 项目中：

  • 使用 dict 存储工具注册表（Tool Registry）
  • 使用 list 管理对话上下文（prompt history）

Q2：你如何保证代码的工程质量？

参考回答：

主要从三个方面保证：

  • 模块化设计（如 Tool 模块 / Agent 模块）
  • 异常处理（API调用失败处理）
  • 代码规范（命名清晰、结构合理）

在项目中：

  • 工具调用逻辑独立为模块
  • Agent Loop 单独封装

二、LLM 应用开发

Q3：LLM API 调用流程是怎样的？

参考回答：

标准流程：

  1. 构建 Prompt（system + user）
  2. 发送请求（model / messages）
  3. 获取返回结果（completion）
  4. 解析输出（文本 / function call）

核心：Prompt 决定模型行为

Q4：什么是 Prompt Engineering？你是怎么用的？

参考回答：

Prompt Engineering 是通过设计输入提示来控制模型输出。

常用方法：

  • 角色设定（system prompt）
  • 输出格式约束
  • 任务拆解（step-by-step）

Q5：什么是上下文窗口（Context Window）？

参考回答：

上下文窗口是模型一次能处理的最大 token 数量。

影响：

  • 输入长度
  • 对话记忆能力

项目中通过控制 prompt history 避免超出限制。

三、AI Agent（重点）

Q6：什么是 Agent？和普通 LLM 有什么区别？

参考回答：

普通 LLM：

  • 输入 → 输出（单轮）

Agent：

  • 感知 → 推理 → 行动 → 反馈（循环）

核心区别：

  • Agent 具备自主决策与工具调用能力

Q7：解释 Thought–Action–Observation Loop

参考回答：

Agent 核心执行机制：

  1. Thought：模型推理
  2. Action：调用工具
  3. Observation：获取结果

循环执行直到任务完成。

Q8：Tool Calling 是怎么实现的？

参考回答：

实现步骤：

  1. 定义工具函数
  2. 在 Prompt 中描述工具
  3. 模型输出 Action
  4. 解析并执行函数
  5. 返回 Observation

本质：

  • LLM 负责决策
  • 代码负责执行

Q9：Agent 为什么需要任务规划（Planning）？

参考回答：

复杂任务无法一步完成，例如旅行规划：

  • 查天气
  • 查景点
  • 生成行程

Planning 是 Agent 核心能力。

四、RAG（检索增强生成）

Q10：什么是 RAG？

参考回答：

RAG = Retrieval + Generation

流程：

  1. 查询问题
  2. 向量检索文档
  3. 拼接到 Prompt
  4. LLM 生成答案

Q11：为什么需要 RAG？

参考回答：

解决：

  • 知识过时
  • 模型幻觉
  • 专业领域知识不足

本质：让模型“查资料再回答”

Q12：如何减少模型幻觉？

参考回答：

方法：

  • 使用 RAG
  • 限制回答来源
  • Prompt 约束

最有效方式：

  • 检索增强（RAG）

五、后端与系统设计

Q13：FastAPI 在项目中的作用？

参考回答：

用于构建接口服务：

  • 提供 Agent API
  • 支持 /chat、/agent 等接口

Q14：如何设计一个可扩展的 Agent 系统？

参考回答：

模块化设计：

  • LLM 模块
  • Tool 模块
  • Memory 模块
  • Agent Loop

工具管理：

  • Tool Registry（字典）

优势：

  • 易扩展
  • 可复用

六、项目深入问题

Q15：项目最大难点是什么？

参考回答：

主要难点：

  1. Prompt 设计（控制输出格式）
  2. Agent Loop 稳定性（解析 Action）

解决方案：

  • 严格格式约束
  • 正则解析

Q16：如果优化项目你会怎么做？

参考回答：

优化方向：

  • 增加 Memory（长期记忆）
  • 引入 RAG
  • 多 Agent 协作
  • 使用 LangGraph 重构

总结（面试重点）

重点方向：

  • Agent（最核心）
  • RAG（高频考点）
  • Prompt Engineering（必问）
