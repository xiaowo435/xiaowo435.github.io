Hexo 常用命令速查

基础命令

命令 说明
hexo init &lt;folder&gt; 初始化一个新的 Hexo 博客
hexo new "文章标题" 创建新文章
hexo new page "页面名称" 创建新页面（如 About、Tags 等）
hexo generate 或 hexo g 生成静态文件
hexo server 或 hexo s 启动本地服务器预览
hexo deploy 或 hexo d 部署网站
hexo clean 清除缓存和已生成的文件

组合命令

命令 说明
hexo s -g 生成并启动本地服务器
hexo d -g 或 hexo g -d 生成并部署
hexo clean && hexo g && hexo d 清除缓存、生成、部署（最常用）

常用参数

参数 说明
-p, --port 指定端口，如 hexo s -p 5000
-o, --open 启动服务器后自动打开浏览器
-w, --watch 监视文件变化并自动重新生成
--draft 渲染草稿文章
--silent 静默模式

文章管理

# 创建文章（默认在 source/_posts/）
hexo new "我的第一篇文章"

# 创建草稿（在 source/_drafts/）
hexo new draft "草稿标题"

# 发布草稿为正式文章
hexo publish "草稿标题"

# 创建带布局的文章
hexo new post "文章标题"
hexo new draft "草稿标题"
hexo new page "页面标题"
