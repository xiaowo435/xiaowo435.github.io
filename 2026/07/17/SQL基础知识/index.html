SELECT 基本语法

SELECT 是 SQL 最基础的语句，用于从表中查询数据：

SELECT 列1, 列2, … FROM 库名.表名 WHERE 条件;

数仓规范：禁止使用 SELECT *，必须明确列出字段名。

为什么需要 JOIN？

数据仓库中数据分布在不同的表中。比如订单表只有 user_id，要获取用户名就需要 JOIN 用户维度表。

JOIN 类型

  • INNER JOIN：只返回两表都匹配的行
  • LEFT JOIN：返回左表所有行，右表无匹配填 NULL
  • RIGHT JOIN：返回右表所有行（较少使用）
  • FULL JOIN：返回两表所有行
  • CROSS JOIN：笛卡尔积（慎用）
    数仓规范：事实表(大表)的 dt 放 WHERE，维度表(小表)的 dt 放 JOIN ON 子句！

子查询是嵌套在其他 SQL 语句中的 SELECT 语句。常见用法：

  • WHERE … IN (子查询)：过滤条件中使用
  • FROM (子查询) t：作为临时表
  • 标量子查询：返回单个值

什么是窗口函数？

窗口函数在不减少行数的情况下，对”窗口”内的数据进行计算。语法：

常用窗口函数

  • ROW_NUMBER()：行号（不并列：1,2,3,4）
  • RANK()：排名（并列跳号：1,1,3）
  • DENSE_RANK()：排名（并列不跳：1,1,2）
  • LAG(col, n)：取前 n 行的值
  • LEAD(col, n)：取后 n 行的值
  • SUM/AVG/COUNT OVER()：窗口内聚合
