🖥️ 系统监控与告警类

这类脚本是运维的“眼睛”，用来时刻盯着服务器的健康状况。

1. 检查系统负载

当系统负荷过高时自动发邮件告警。

#!/bin/bash

设置负载阈值

threshold=1.0

获取系统最近1分钟的平均负载

load=$(uptime | awk -F’[, ]+’ ‘{print $(NF-2)}’)

判断是否超过阈值

if (( $(echo “$load > $threshold” | bc -l) )); then
   echo “系统负载过高: $load” | mail -s “系统负载警报” admin@example.com
fi

知识点：uptime查看负载，awk提取数据，bc进行浮点数比较。

2. 监控磁盘使用率

当磁盘分区使用率超过80%时发送邮件报警。

#!/bin/bash
THRESHOLD=80
EMAIL=”admin@example.com“

获取磁盘使用率，排除不需要的文件系统

df -H | grep -vE ‘^Filesystem|tmpfs|cdrom’ | awk ‘{ print $5 “ “ $1 }’ | while read output; do
   usep=$(echo $output | awk ‘{ print $1 }’ | cut -d’%’ -f1)
   partition=$(echo $output | awk ‘{ print $2 }’)
   if [ $usep -ge $THRESHOLD ]; then
       echo “分区 "$partition" 已使用 ${usep}%，请及时处理！” | mail -s “磁盘空间告警: $partition” $EMAIL
   fi
done

知识点：df -H查看磁盘空间，grep -vE过滤不需要的行，while read循环处理每一行输出。

3. 监控服务状态并自动重启

检查Nginx服务是否运行，如果挂了就尝试重启，并发送通知。

#!/bin/bash
SERVICE=”nginx”
EMAIL=”admin@example.com“

检查服务是否运行

if ! systemctl is-active –quiet $SERVICE; then
   echo “$SERVICE 服务已停止，正在尝试重启…” | mail -s “$SERVICE 服务告警” $EMAIL
  systemctl restart $SERVICE
   # 检查重启是否成功
   if systemctl is-active –quiet $SERVICE; then
       echo “$SERVICE 服务已成功重启” | mail -s “$SERVICE 服务恢复” $EMAIL
   else
       echo “重启 $SERVICE 服务失败，请立即人工介入！” | mail -s “$SERVICE 重启失败” $EMAIL
   fi
fi

知识点：systemctl is-active --quiet静默检查服务状态。

💾 数据备份与清理类

备份是“后悔药”，而清理是防止磁盘被日志“撑爆”的必要手段。

4. 定期备份MySQL数据库

将指定数据库导出为.sql文件，并自动删除7天前的旧备份。

#!/bin/bash
BACKUP_DIR=”/backup/mysql”
MYSQL_USER=”root”
MYSQL_PASSWORD=”your_password”
DATABASE_NAME=”mydatabase”
​

创建备份目录（如果不存在）

mkdir -p $BACKUP_DIR

执行备份，文件名包含当前日期

mysqldump -u $MYSQL_USER -p$MYSQL_PASSWORD $DATABASE_NAME > $BACKUP_DIR/${DATABASE_NAME}-$(date +%Y%m%d).sql

删除7天前的备份文件

find $BACKUP_DIR -type f -mtime +7 -exec rm {} ;

知识点：mysqldump是MySQL的备份命令，find ... -mtime +7查找7天前修改的文件并删除。

5. 清理过期日志文件

删除指定目录下7天前的所有.log文件。

#!/bin/bash
log_dir=”/var/log/myapp”
days_to_keep=7
find “$log_dir” -type f -name “*.log” -mtime +$days_to_keep -delete

知识点：find命令功能强大，可以按文件名(-name)、类型(-type)、修改时间(-mtime)查找文件并执行操作(-delete)。

🚀 自动化部署与批量操作类

当需要管理几十上百台服务器时，手动操作一台台去配置几乎是不可能的。

6. 批量部署SSH密钥

将管理机的公钥自动复制到多台服务器上，实现免密登录。

#!/bin/bash

定义服务器列表

SERVERS=(“server1” “server2” “server3”)
USER=”root”
KEY_FILE=”/home/$USER/.ssh/id_rsa.pub”
​
for server in “${SERVERS[@]}”; do
   echo “正在部署密钥到 $server …”
  ssh-copy-id -i $KEY_FILE $USER@$server && echo “成功” || echo “失败”
done

知识点：for循环遍历服务器列表，ssh-copy-id是专门用于部署SSH密钥的命令。

7. 多服务器文件同步

将本地目录同步到多台服务器的指定目录。

#!/bin/bash
servers=(“server1” “server2” “server3”)
source_dir=”/path/to/your/app”
destination_dir=”/path/on/server”
​
for server in “${servers[@]}”; do
  rsync -avz “$source_dir” “$server:$destination_dir”
done

知识点：rsync是一个高效的文件同步工具，-avz是归档、详细输出、传输时压缩的常用组合。

🆘 应急处理类

这类脚本用于快速排查和解决突发的线上问题。

8. 检查端口占用

快速查看某个端口是否被占用，以及被哪个进程占用。

#!/bin/bash
if [ -z “$1” ]; then
   echo “用法: $0 <端口号>”
   exit 1
fi
PORT=$1
echo “>>> 正在检查端口 $PORT …”
lsof -i:$PORT || echo “端口 $PORT 未被占用”

知识点：lsof -i:端口号是查看端口占用的标准方法，$0代表脚本本身。

9. 清理僵尸进程

查找并强制清理系统中的僵尸进程。

#!/bin/bash
echo “>>> 正在查找僵尸进程…”
ZOMBIE=$(ps -ef | grep defunct | grep -v grep | awk ‘{print $2}’)
if [ -n “$ZOMBIE” ]; then
echo “>>> 尝试杀死僵尸进程: $ZOMBIE”
kill -9 $ZOMBIE
else
echo “>>> 未发现僵尸进程”
fi

知识点：ps -ef | grep defunct用于查找僵尸进程，kill -9是强制终止进程的信号。
