📂 文件与目录管理

命令 作用 示例
ls 列出目录内容 ls -lah 以详细格式列出所有文件（包括隐藏文件），并显示人类可读的大小
cd 切换当前工作目录 cd /var/log 进入 /var/log 目录
pwd 显示当前工作目录的完整路径 pwd 输出类似 /home/username
cp 复制文件或目录 cp -r /source /destination 递归复制整个目录
mv 移动或重命名文件/目录 mv old_name.txt new_name.txt 重命名文件
rm 删除文件或目录 rm -rf /tmp/test 强制递归删除 /tmp/test 目录（高危操作，慎用！）
mkdir 创建新目录 mkdir -p /data/logs 创建目录，如果父目录不存在则一并创建
ln 创建链接文件 ln -s /usr/local/nginx /nginx 为目录创建一个软链接（符号链接）
find 在目录树中查找文件 find /var/log -name "*.log" 在 /var/log 下查找所有以 .log 结尾的文件
du 查看文件或目录的磁盘使用情况 du -sh /var/log 统计 /var/log 目录的总大小
tree 以树形结构显示目录内容 tree -L 2 以树形结构显示当前目录，最多显示2层

🖥️ 系统监控与性能分析

命令 作用 示例
top / htop 实时查看系统进程和资源占用（CPU、内存） top -c 显示完整的命令；htop 提供更友好的交互界面
ps 显示当前进程的快照 ps aux 查看所有运行中的进程；`ps aux \
free 查看内存使用情况 free -h 以人类可读的格式显示内存和Swap使用情况
df 查看磁盘分区空间使用情况 df -h 以人类可读格式显示所有文件系统的磁盘空间
vmstat 报告虚拟内存、进程、CPU活动等系统整体情况 vmstat 1 5 每秒刷新一次，共显示5次，用于排查系统瓶颈
iostat 监控磁盘I/O性能 iostat -x 1 显示扩展统计信息，每秒刷新一次，用于分析磁盘瓶颈
uptime 查看系统运行时间、用户数和平均负载 uptime 输出系统已运行时间、当前登录用户数和1、5、15分钟的平均负载
uname 显示系统信息 uname -a 显示内核版本、主机名、硬件架构等所有系统信息
hostnamectl 查看或修改主机名及操作系统版本 hostnamectl 显示当前主机名及系统详细信息

🌐 网络诊断与管理

命令 作用 示例
ping 测试网络连通性和延迟 ping -c 4 example.com 向 example.com 发送4个ICMP包测试连通性
ss / netstat 查看网络连接、路由表、接口统计等信息 ss -tulnp 查看所有TCP/UDP监听端口及对应进程（比netstat更快）
traceroute 追踪数据包到达目标主机的路由路径 traceroute example.com 显示到 example.com 经过的每一跳路由
dig 查询DNS解析信息 dig example.com 查询 example.com 的DNS解析记录
tcpdump 网络抓包分析工具 tcpdump -i eth0 port 80 -w capture.pcap 抓取网卡 eth0 上80端口的流量并保存到文件
iftop / nethogs 实时查看网络带宽占用 iftop -i eth0 按IP显示流量；nethogs eth0 按进程显示流量
curl 命令行HTTP客户端，用于测试接口或网页 curl -I https://linux.org 只获取HTTP头部信息，用于测试服务是否正常
ip 网络接口配置（推荐替代ifconfig） ip a 查看所有网络接口及其IP地址
scp 跨服务器安全传输文件 scp file.txt user@remote:/path/ 将本地文件复制到远程服务器
rsync 高效的文件同步工具（支持增量同步） rsync -avz --delete /data/ user@remote:/backup/ 将本地 /data/ 同步到远程，并删除目标端多余文件

⚙️ 进程与服务管理

命令 作用 示例
kill 终止进程 kill -9 PID 强制终止指定PID的进程
pkill 按进程名终止任务 pkill nginx 终止所有名为nginx的进程
systemctl 管理系统服务（Systemd） systemctl status nginx 查看nginx服务状态；systemctl start nginx 启动服务
crontab 管理定时任务 crontab -e 编辑当前用户的定时任务列表

📝 日志与文本处理

命令 作用 示例
cat 查看文件内容 cat /var/log/auth.log 查看认证日志文件内容
tail 查看文件末尾部分，常用于查看最新日志 tail -f /var/log/nginx/access.log 实时跟踪nginx访问日志的更新
grep 在文件中搜索文本 grep "ERROR" /var/log/syslog 在系统日志中搜索包含”ERROR”的行
awk 强大的文本分析工具 awk '{print $1}' access.log 提取日志文件的第一列（如IP地址）
sed 流编辑器，用于文本替换等 sed 's/old/new/g' file.txt 将文件中的所有”old”替换为”new”
journalctl 查看systemd管理的日志 journalctl -u nginx -f 实时查看nginx服务的日志
dmesg 显示内核环缓冲区信息，用于查看硬件相关日志 `dmesg \

👥 用户与权限管理

命令 作用 示例
chmod 修改文件或目录的权限 chmod 755 script.sh 设置脚本权限为所有者读写执行，组和其他用户读和执行
chown 修改文件或目录的所有者和所属组 chown user:group file.txt 将文件的所有者改为user，组改为group
useradd 创建新用户 useradd newuser 创建一个名为newuser的新用户
passwd 修改用户密码 passwd newuser 为newuser设置或修改密码
id 查看用户的UID、GID和所属组 id username 显示指定用户的ID信息

📦 软件包与压缩管理

命令 作用 示例
yum / apt Linux软件包管理器（不同发行版） yum install nginx (CentOS/RHEL) 或 apt install nginx (Ubuntu/Debian) 安装nginx
tar 打包、压缩和解压文件 tar -czvf backup.tar.gz /data 将 /data 目录压缩为 backup.tar.gz
zip / unzip 处理 .zip 格式的压缩文件 zip -r archive.zip folder 将 folder 目录压缩为 archive.zip

🛠️ 其他高频工具

命令 作用 示例
history 显示历史命令记录 `history \
alias 为长命令创建别名 alias ll='ls -lah' 之后输入ll即相当于执行ls -lah
ssh 远程连接到另一台计算机 ssh user@192.168.1.100 以user身份远程登录到IP为192.168.1.100的服务器

实战组合技巧

  • 管道 (|)：将前一个命令的输出作为后一个命令的输入。

    • cat access.log | grep "ERROR" | wc -l：统计access.log中”ERROR”出现的次数。

  • 重定向 (> >>)：将命令输出保存到文件。

    • ls -lh > file_list.txt：将当前目录的列表信息覆盖写入到file_list.txt文件。

  • 查找并批量处理：

    • find /var/log -type f -name "*.log" -mtime +7 -delete：删除/var/log下所有7天前修改的.log文件。
